# Cubed Launcher

A GPL-3.0-only fork of [Millida Launcher](https://github.com/millida/launcher),
modified on 2026-11-01. See [README.ru.md](README.ru.md) for setup, build and validation limits.

Cubed provides Microsoft account login, local Minecraft instances and direct Modrinth
content browsing. The main shell excludes Millida accounts, shops, battle pass,
virtual currencies, social services, hosting and promotions. CurseForge is excluded.
Telemetry, presence reporting, remote UI/translation delivery and Millida updates are disabled.
Own Microsoft application registration is required; Millida's client ID is not reused.
